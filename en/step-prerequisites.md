# Step prerequisites

`1A` is the one hard prerequisite. The learner must run the starter on a connected Pico and see the LED and ready message before testing any circuit. It is still fine to read ahead.

| Pages | Check before testing | If it is missing |
| --- | --- | --- |
| `2A`–`2D` body | No other build step | Craft now; leave access to the Pico, cable, wires and buzzer. |
| `3A`–`3B` buzzer | `1A` and a suitable 3.3 V part | Return to `1A`, then use the chosen buzzer page's diagram. |
| `4A` beeps | `3A` or `3B` tested | Return to the buzzer page you chose. |
| `4B` notes, `4C` slides | `3B` tested | Use a passive buzzer; an active one cannot play changing pitches. |
| `5A`–`5J` controls | `1A` tested | You can read or plan first; test readings after wiring. |
| `6A`–`6C` code | Chosen buzzer and controls tested separately | Optional reminder: revisit the part tests if needed, then join their scripts. The code pages remain open. |
| `7A` play | A sound responds to an action | Revisit a combining page or your own program, then play and change it. |
| `8A`–`8D` ideas | Only the parts the learner chooses to borrow | Follow the linked part pages and return to the idea. |

Warnings inside learner pages point back to relevant tests. They do not prescribe which body, input or instrument to make.
